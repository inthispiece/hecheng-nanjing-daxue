# 合成南京大学

手机和电脑均可玩的校徽物理合成游戏。无账号、后端、广告或外部 CDN 依赖。

GitHub Pages 入口：https://inthispiece.github.io/hecheng-nanjing-daxue/

## 玩法

- 电脑移动鼠标瞄准、点击投放；方向键移动、空格投放，P 暂停。
- 手机按住棋盘拖动、松手投放。拖出棋盘会取消投放。
- 两个相同校徽碰撞后合成下一级，首次合成南京大学即通关。
- 校徽持续越过警戒线 2 秒后结束；新投放球有 1 秒缓冲。

合成顺序：蓝翔技校 → 南京理工大学 → 东南大学 → 西安交通大学 → 浙江大学 → 复旦大学 → 清华大学 → 北京大学 → 南京大学。

## 本地使用与发布

下载整个仓库并打开 `index.html` 即可离线试玩，保留 `assets`、`js` 和 `vendor` 文件夹。最高分和静音设置保存在当前浏览器，不会跨设备或域名同步。

本仓库直接存放可发布的静态文件。GitHub Pages 使用 `main` 分支的根目录，不需要构建。`.nojekyll` 保留原始目录结构。

`github.io` 的实际可访问性取决于所在网络；托管成功不代表所有地区均可稳定访问。
